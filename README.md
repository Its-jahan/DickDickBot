# 🍆 DickDickBot (Python Edition)

ربات تلگرامی برای رشد دودول، بازی در لیگ‌های گروهی و ایجاد چالش با دوستان! این ربات بر پایه پایتون و دیتابیس **Supabase (PostgreSQL)** نوشته شده و کاملاً با گروه‌های تلگرامی سازگار است.

## 🌟 ویژگی‌ها

- **لیگ‌های گروهی:** هر گروه لیدربرد و سایز مستقل خودش را دارد!
- **چالش‌ها (PvP):** می‌توانید با دوستانتان شرط‌بندی کنید و تاس بریزید.
- **اینلاین بات (`@dickchallengerbot`):** تمامی امکانات ربات بدون شلوغ کردن گروه از طریق دکمه‌های شیشه‌ای (Inline) در دسترس هستند.
- **سیستم آیتم‌ها (Inventory):** امکان پیدا کردن آیتم‌های مختلف (ویاگرا، شیر موز، کاندوم و...) و استفاده از آن‌ها در چالش‌ها برای تغییر نتیجه.
- **پرک‌های روزانه (Perks):** هر روز بعد از رشد دادن، یک لقب/پرک به شما داده می‌شود که روی شانس شما در چالش‌ها تأثیر می‌گذارد (مثلاً کص‌کش، خایه‌مال و غیره).
- **اهدای سایز:** می‌توانید از سایز خودتان به دوستانتان اهدا کنید.
- **اجماع:** اعضای گروه می‌توانند رأی‌گیری کنند تا ۳۰٪ از سایز یک نفر کم شود؛ برای موفقیت به رأی اکثریت اعضای گروه نیاز است.

## 🎮 دستورات

- `/d` یا `/grow` یا `/dick` - رشد دادن دودول
- `/c [عدد]` یا `/challenge [عدد]` - ایجاد یک چالش با شرط دلخواه
- `/t` یا `/top` - نمایش لیدربرد گروه
- `/i` یا `/inv` - نمایش کیف پول آیتم‌ها
- `/u [نام آیتم]` یا `/use [نام آیتم]` - استفاده از یک آیتم در چالش بعدی
- `/dd @username [مقدار]` - اهدای سایز به شخص دیگر
- `/ejma @username` یا ریپلای + `/ejma` - شروع رأی‌گیری اجماع علیه یک نفر (۳۰٪ از سایز فعلی‌اش کم می‌شود در صورت رأی‌آوری)

### ⚖️ نحوهٔ کار اجماع

- حد نصاب رأی برابر است با اکثریت مطلق اعضای فعال گروه (`تعداد اعضا ÷ ۲ + ۱`؛ مثلاً برای ۶ نفر، ۴ رأی لازم است).
- با شروع اجماع، مقدار کسر (۳۰٪ از سایز فعلی هدف) و حد نصاب لازم، ثابت می‌شوند و در طول رأی‌گیری تغییر نمی‌کنند.
- اگر رأی‌گیری به حد نصاب نرسد و کسی دوباره علیه همان فرد اجماع بسازد، آن اجماع شکست‌خورده تلقی می‌شود و آن فرد به مدت **۳ روز** در برابر اجماع جدید محافظت می‌شود.
- هر عضو گروه فقط یک‌بار می‌تواند به هر اجماع رأی دهد و هدف نمی‌تواند به اجماع علیه خودش رأی بدهد.

## 🚀 استقرار و نصب

۱. کلون کردن ریپازیتوری:
```bash
git clone https://github.com/Its-jahan/DickDickBot.git
cd DickDickBot/python_bot
```

۲. نصب پیش‌نیازها:
```bash
pip install -r requirements.txt
```

۳. تنظیم توکن در فایل `bot.py`:
```python
TOKEN = 'YOUR_BOT_TOKEN_HERE'
```

۴. اتصال به دیتابیس Supabase:

از داشبورد پروژه Supabase به مسیر **Settings → Database → Connection string** بروید و رشتهٔ اتصال «Transaction» (پورت `6543`) را کپی کنید، سپس آن را در متغیر محیطی `SUPABASE_DB_URL` قرار دهید:
```bash
export SUPABASE_DB_URL="postgresql://postgres.<ref>:<password>@aws-0-<region>.pooler.supabase.com:6543/postgres"
```
جدول‌های مورد نیاز در اولین اجرای ربات به‌صورت خودکار ساخته می‌شوند (`CREATE TABLE IF NOT EXISTS`) و داده‌های موجود با ری‌استارت‌های بعدی پاک نمی‌شوند.

۵. اجرای ربات:
```bash
python bot.py
```
*(یا استفاده از فایل سرویس `dickbot.service` برای اجرای بک‌گراند — مقدار `SUPABASE_DB_URL` را داخل همان فایل تنظیم کنید)*

## 📦 بکاپ‌گیری

داده‌ها اکنون در دیتابیس PostgreSQL پروژه Supabase شما ذخیره می‌شوند. از داشبورد Supabase می‌توانید بکاپ‌گیری خودکار را فعال کنید یا با `pg_dump` به‌صورت دوره‌ای بکاپ بگیرید.
